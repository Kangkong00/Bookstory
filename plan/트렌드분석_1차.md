# 인기 쇼츠 분석 1차 (웹 검색, 2026-11-26)

## 결론
- "전래동화를 비튼 AI 실사 쇼츠"는 검색으로 확인되는 경쟁작이 거의 없다(유머 쇼츠 1편, 나머지는 원작에 충실한 유아용). 빈자리일 수 있지만, 수요가 있다는 증거도 아직 없다(확인 필요).
- 가장 크게 터진 AI 이야기 영상(Fruit Love Island)의 성공 이유는 AI가 아니라 **형식**이었다. 누구나 아는 틀에 엉뚱한 배역을 넣고, 연재로 이어 가며, 시청자가 참여하게 했다.
- 검색으로 얻은 수치는 대부분 블로그나 개인 사례다. 구조 참고용으로만 쓰고, 수치 근거로는 쓰지 않는다.

## 사례
| 사례 | 확인된 내용 | 우리에게 주는 의미 |
|---|---|---|
| Fruit Love Island (2026-03, 틱톡·유튜브) | 9일 만에 약 3억 회(보도마다 다름). 리얼리티 쇼 형식을 과일이 연기. 매일 연재, 팬 투표 | 아는 틀 + 엉뚱한 배역 + 연재 + 참여 |
| 한국 AI 기괴 세계관 계정(서담시, 노점프스케어 등) | AI의 어색함을 공포·기괴 감성으로 역이용 | 조회는 되지만 우리 톤 규칙(A안 기각 사유)과 충돌. 쓰지 않음 |
| AI 숏드라마 언급량(썸트렌드) | 2026년 6월 94건 → 9월 565건 | 시장은 커지는 중 |
| 오픈서베이 조사 | AI 콘텐츠 느낌 1위 "인위적이고 어색함"(49.9%), "AI임을 밝혀야" 85.6% | 실사 품질이 핵심. AI 고지는 필수 |
| 흥부놀부 반전 유머 쇼츠 | 놀부가 흥부를 따라 하다 산신령의 한마디로 뒤집힘 | 같은 장르의 유일한 확인 사례. 조회수 확인 필요 |
| Jenny Hoyos 구조(본인 주장) | 훅 → 3초 이내 예고 → "그런데/그래서" 전개 → 반전 결말 | 우리 4단계 표와 같은 방향 |
| 9초 쇼츠 500만 회(개인 사례) | 일부러 "불편한 지점"을 넣어 댓글을 유도 | 논쟁거리가 댓글을 부른다(일반화 어려움) |

## 뽑은 패턴 6개와 D1 채점
| 패턴 | D1 | 메모 |
|---|---|---|
| P1 아는 틀 + 엉뚱한 변화 | 통과 | 원작 명장면으로 시작 |
| P2 "그런데/그래서" 연쇄 + 반전 결말 | 통과 | 잘함 → 그래서 일이 늚 → 그래서 멈춤 |
| P3 끝이 처음으로 이어짐(반복 시청) | 통과 | 밑 빠진 독 → 아무도 안 막은 독 |
| P4 댓글 논쟁거리 | 보강 필요 | "콩쥐가 잘한 걸까?"를 끝에 질문으로 남길 것 |
| P5 연재·시청자 참여 | 없음 | 끝에 "다음엔 누가 일손을 놓을까요?" 투표형 고정 댓글 검토 |
| P6 AI 어색함 피하기 | 위험 | 숫자가 늘어나는 장면(독 수십 개, 두꺼비 떼)은 AI가 뭉개기 쉬움. 프롬프트에서 개수 제한 |
