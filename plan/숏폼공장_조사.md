# 깃허브 숏폼 공장 조사 (2026-11-27)

## 결론
- 무료이면서, 같은 얼굴을 유지하고, 한국어까지 되는 공장은 찾지 못했다.
- 얼굴 유지를 제대로 하는 곳은 모두 유료 API를 쓰거나 고성능 그래픽카드가 필요하다.
- 코드를 그대로 가져오기보다 **방법 두 가지**를 가져온다: ① 매 컷에 캐릭터 기준 사진을 함께 넣기 ② 컷마다 얼굴이 기준과 같은지 검사(얼굴 검수 단계).

## 2차: 코드 직접 확인 (2026-11-27)
### MoneyPrinterMax (코드 약 3,500줄)
- 얼굴 유지 방법: Google Flow의 '재료(ingredients)' 기능에 캐릭터 사진을 자동으로 붙이는 것. 우리가 Flow에서 @캐릭터로 하는 것과 같은 원리다. 더 강한 얼굴 유지 기술은 없다.
- 실제로 더해 주는 것: 프롬프트 입력·생성·내려받기 클릭 자동화(Chrome 원격 조작, 화면 요소 조작 코드 1,992줄).
- 편집: Remotion(우리와 같은 도구).
- 목소리: 코드상 Cartesia·ElevenLabs(유료)만 있음. 소개 문구의 edge-tts는 코드에 없음.
- 위험: 별 2개·인도네시아어·검증 안 됨. Flow 화면이 바뀌면 깨짐. 대표 PC에서 Chrome을 디버그 모드로 띄워야 함. 구글 계정 자동 조작이 약관 위반으로 계정 정지될 가능성(추측, 확인 필요). 수상한 외부 전송 코드는 발견하지 못함.
### MoneyPrinterTurbo
- 무료 한국어 음성: Edge TTS 한국어 목소리 3종(인준 남, 선희 여, 현수 다국어).
- 직접 만든 사진·영상을 재료로 쓰는 'local' 모드 있음.
- 약점: 클립을 이야기 순서와 초 단위로 맞추는 편집이 아니라, 나레이션 길이에 클립을 채우는 정보형 구조. 비트 시트형 동화에는 우리 Remotion이 더 맞음.
- 이 환경에서 Edge TTS 시험: 네트워크가 음성 서버(speech.platform.bing.com)를 막아 실패. Edge TTS의 상업 이용 조건은 확인 필요.

## 방법 (작가 추천)
1. MoneyPrinterTurbo에서 **무료 한국어 음성(Edge TTS)만** 떼어 우리 Remotion에 붙인다 → 두꺼비 목소리 나레이션.
2. MoneyPrinterMax의 **작업 흐름**을 따라 한다: 비트 시트 → 컷별 프롬프트와 캐릭터 재료를 정리한 'Flow 일괄 작업표' 자동 생성 → 대표는 복사·붙여넣기만. 자동 클릭은 하지 않는다(계정 위험).
3. 자동 클릭 시험은 나중에, 별도 구글 계정으로 대표 PC에서만(선택).
