# 영상 편집을 Claude Code에 맡기는 프롬프트

> 출처: https://thedalbee.com/downloads/claude-edit-allinone-prompt.md (2026-11-26 받음)

달비(@thedalbee)가 영상 "프리미어 한 번도 안 열었습니다"에서 5분짜리 녹화 영상을 인트로로 편집할 때 붙여 넣은 프롬프트 원문입니다.

## 쓰는 법

1. Claude Code 데스크톱 앱 코드 탭에서 작업 폴더를 고르고 모델은 Opus 5.5로 고릅니다.
2. 편집할 녹화 영상 파일을 입력 창에 끌어다 놓습니다.
3. 아래 프롬프트 전체를 복사해 붙여 넣고 보냅니다.

## 프롬프트

```text
이 영상을 유튜브 인트로로서 쓰기 위해서 편집을 할 거고, 내가 말을 반복하거나 절거나 무음 구간으로 침묵한 구간에 대해서는 전부 다 잘라내 주고 완전한 인트로 영상으로 만들어줬으면 좋겠어
작업 방식을 설명할게 1단계, 위스퍼 라지3 터보를 설치해
두 번째로 그걸 전사한 후에 오디오 파형도 같이 한번 이미지 렌더링해서 봤으면 좋겠어
그 이후에 내가 방금 언급했던 모든 구간을 잘라주고 자막도 깔끔하게 뽑아줬으면 좋겠는데, 자막의 가독성을 위해서 뒤편에 검은색 박스를 쳐서 프리텐다드 폰트를 사용한 흰색 자막을 만들어주면 좋을 것 같아
자막 분절에 대해서도 굉장히 큰 신경을 써줬으면 좋겠는데, 자막 분절의 경우에는 넷플릭스 자막 기본 원칙을 참고하되 그거는 두 줄짜리 원칙이니까 한 줄로 처리하면 좋을 것 같아 한국어 기본은 자막이 한 줄씩 한 줄씩 나오는 거야
그리고 다음 단계로 하이퍼프레임이라는 걸 설치해 줘
하이퍼프레임을 설치한 후에 인트로 영상에 걸맞는 모션 그래픽을 만들어주면 좋을 것 같아 하이퍼프레임 안에 있는 템플릿을 충분히 사용해도 되고, 만약에 내가 이 컴퓨터에서 얘기했던 것 중에 괜찮은 게 하나 있다면 그걸 사용해서 만들어줘도 좋을 것 같아
영상이 완료되면 새로운 에이전트를 하나 띄워서 영상을 검수 한번 하도록 하고 이후에 수정까지 처리해
전부 완료되면 영상을 띄워주면 돼
```

영상 속 입력 그대로입니다. 작업 중 허용 창이 계속 뜨면 자동 모드로 바꿉니다.
